# Collection-Specific Operations

This directory preserves runbooks and helper scripts for specific collection
ingests and dated batches. These are operational records, not part of DART's
general desktop or headless application interface.

## Contents

- [Cyclone Yearbooks](./collections/cyclone_2026/CYCLONE-YEARBOOKS-20261101.md)
- [Reunion 2026 Oral Histories](./collections/reunion_2026/REUNION-2026-ORAL-HISTORIES.md)
- [October 29 Final-Three Batch](./batches/2026-10-29/FINAL-THREE-20261029.md)
- [October 29 Overnight Batch](./batches/2026-10-29/OVERNIGHT-20261029.md)
- [October 30, 2026 Oral-History Batch](./batches/oral_histories_2026_10_30/ORAL-HISTORIES-20261030.md)

Reusable DART launchers, headless workflows, and shared operational helpers
remain in `scripts/` and the application modules. Collection-specific files
may contain historical collection names, paths, counts, and approvals. Review
those details before reusing a command; do not assume that past approval
applies to a new run.
